> Refaktrs ChatGPT Python Application

Python

In this project, I created a simple GUI application using Tkinter in Python for interacting with the OpenAI ChatGPT API. The application allows the user to input their API key, select a model, set parameters like temperature and frequency penalty, and enter a message to send to the OpenAI API for generating a response. It also deals with history, allowing for the chat to be ongoing with knowledge of past conversation.
